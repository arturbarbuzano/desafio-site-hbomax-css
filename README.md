# Desafio Site HBO Max

Olá, esse projeto foi realizado como parte da trilha de Formação Desenvolvedor CSS da plataforma DIO no qual o desafio consistia em desenvolver um clone do site da HBO Max. A ideia era reproduzir a interface, com algumas modificações, aplicando os temas abordados ao longo das aulas de CSS da plataforma da DIO

[Clique aqui](https://arturbarbuzano.github.io/desafio-site-hbomax-css/) para acessar a minha versão do site da HBO Max.
